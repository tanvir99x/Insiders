# Tasks

Edit `tasks.js` to manage the Tasks tab. This local folder is the single place to add, remove, reorder, or customise tasks. Each task needs a unique numeric `id`, a `title`, an `xp` amount, a short `desc`, and an optional direct `link`.

Example:

```js
{ id: 11, title: 'Join the community call', xp: 20, desc: 'Attend this week’s Base community call.', link: 'https://example.com/community-call' }
```
